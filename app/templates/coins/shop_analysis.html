口径说明
  • 成交率 = 成交 /（成交 + 流拍），不含在拍；有效样本 = 成交 + 流拍。
  • 竞价率 = 成交拍品中出价人数 ≥2 的占比，只统计有出价数据的样本；单元格小字为覆盖率（有出价数据样本 / 全部样本），无数据显示「—」。
  • 竞争热度：场均围观人数 / 次数按专场取值后再取中位数；场均出价人数按专场内出价人列表去重、场均出价次数按专场内所有拍品累加，再分别取各专场中位数；出价人明细不在页面展示。出价转化率 = 出价人数 ÷ 围观人数，仅对已结束场次计算。
  • 同标题价差 = 本店成交价中位数 ÷ 全平台同标题成交中位数 − 1；同标题成交样本 <5 条显示「—」，不扣分。同标题只作可比样本，不作为异常依据；详情另列同分类价差。
  • 起拍价为 0 的拍品占比仅作数据说明，不参与评分。
  • 同图重挂 = 同一 oss_key 在本店流拍后于后续专场再次出现；排除店铺模板图（同一 oss_key 出现 ≥10 次或跨 ≥5 家店）；≥3 次标红。标题相同不视为异常。
  • 出价人集中 = 单一出价人占本店成交 ≥60% 且样本 ≥10；热度覆盖不足 = 有出价数据样本占比过低。
  • 疑似托价（参考）= 同一 uid 在本店出价 ≥10 场但中签率 ≤10%，且此类 uid 的出价次数占本店 ≥20%；只在有出价数据的样本上计算，覆盖率 <30% 时只展示不参与评分。
  • 评分权重：成交真实度 30%（成交率 60% + 竞价率 40%，无出价数据按成交率归一）· 竞争热度 20%（场均出价人数与出价转化率分档，无数据不扣分、按可得权重归一）· 价格合理 20%（同标题价差绝对值越小越高，无基准不计分）· 交付条件 20%（佣金率、运费、发货天数、是否可寄存）· 样本可信 10%（≥30 条满分，5–30 条线性，<5 条「样本不足」不计分）。
  • 店铺口径仅本平台已见场次，不代表该店全量经营情况；缺失字段不扣分，按可得权重归一。
  • 麦稀奇在 App / 小程序内，本站不提供店铺外链；「前往今日拍场」只跳本站当天的场次页。
  • 免责声明：本页为买家侧参考，不构成交易建议；历史成交可能滞后。
