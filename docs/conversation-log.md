# 对话记录格式约定

> 由 `RULES.md` §零.6 触发：**调用过子代理的轮次**才写 `data/conversations/{YYYY-MM-DD}.md`（按天、追加写入）；
> 没调用子代理的轮次不写文件，也不留空轮。只记入口与出口，不记执行过程，不回读整份文件。
> 记录文件不进版本控制（见 `.gitignore`）。

## 记四样

用户原话 / 主对话→子代理的输入 / 子代理→主对话的输出 / 主对话的最终回复。

## 格式

1. 标题层级只用三级：`#` 会话（`对话记录 · {会话主题}`）→ `##` 轮次（`第 N 轮 · HH:MM ｜ N 个子代理`）→ `###` 用户 / 主对话 / 我的回复 / 回执。
2. 子代理**不用标题**，用加粗行 `**{name}**`；不加序号、不加「产出」行。
3. 每个子代理固定两段：`**输入**` 的内容整体放进 `>` 引用块（空行也写 `>` 保持连续）；
   `**输出**` 留在普通正文，保留 Markdown 表格 / 列表 / 加粗。
4. 轮次之间、子代理之间用 `---` 分隔。
5. 每轮末尾是 `### 回执` 表，列为「执行者 / 轮数 / 搜索与读取 / 写入与命令 / 越界项」。
6. 同一文件内另起会话：先写一行 40 个 `#`，再起新的 `#` 会话标题。
