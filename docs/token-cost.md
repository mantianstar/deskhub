# token 成本清单口径

> 从 [RULES.md](../RULES.md) §零.3 分册出来的计费细则；门禁与回执格式仍在 RULES。
> 目的：回执里的成本表能直接与平台账单对比。

## 1. 表格与口径

| 轮 | 动作 | 对象 | 新增输入 | 累计上下文 | 输出 | 轮成本 |
|---|---|---|---|---|---|---|
| 1 | 读取 | `RULES.md` §零 | 72 | 19642 | 35 | 19677 |
| **合计** | - | - | - | **19642** | **35** | **19677** |

- **口径**：第 N 轮输入 = 固定底座（默认 19570，2026-10-26 首个真实请求实测，约占 1M 窗口 2%）+ 前 N-1 轮全部消息 + 第 N 轮新增消息；轮成本 = 输入 + 输出。
- **底座构成**：system 提示 + 全部工具与技能定义 + memory 注入（实测约 1.5k）+ 环境与打开文件注入。**只含本次请求自带的内容，不含历史轮次**；在已有历史的会话里反推会把历史算进底座，导致虚高（旧的 5.2 万即此因）。
- **请求数**：平台「新增请求」多于对话轮次——**每次工具往返都单独算一次请求**，每次都要重发整个上下文。成本表按请求逐行列，不按对话轮次列；回执同时记「对话轮次 / 平台请求数」。
- **轮 = 批次（仅参考）**：按本轮已落盘的请求数算（`guard_budget.py` 计量后注入，模型照抄）——一条请求里的并行工具调用算同一轮，不再用调用间隔猜批次；预算与检查点按「请求数 + 累计输入」，不按轮数。
- **上下文（回执参考）**：起点认本轮首条「提问」的 `prompt_tokens`，终点取本轮末条已完成请求；本轮流水还没落盘时显示「待落盘」，跨任务不兜底。
- **累计输入**：本会话起点（`guard_reset` 记的 `created_ts`）至今所有 `prompt_tokens` 之和，含子代理请求；只用于 400k / 800k / 1.2M 判档，**不进回执**（与成本行的「输入」是同一个数）。
- **动作 / 对象**：代理从请求体最后一条消息推——工具名映射动作（`Read`→读取、`SearchReplace`→编辑、`RunCommand`→命令），首个关键参数当对象（文件路径 / 命令 / 搜索词）；语义补充只在回执里写，不进日志。**对象只记标识，不抄全文**：用户提问取文本块里的原话前 30 字（`<system-reminder>` 注入不计）；表格里文件路径按仓库相对路径显示，其余对象截到 30 字。

## 2. 校准与对账

- **校准**：用平台的「当前上下文 + 请求数 + 总 tokens」反推底座（`--context-start / --context-now / --requests / --total`）。**先确认三个数字同一区间**：「当前上下文」是累计值，而「新增请求 / 总 tokens」在重启或刷新后可能只记增量（例：8 万上下文的会话显示 2 次请求 / 15 万，是增量而非全程）；区间不同就直接相减会得出荒谬结论。
- **对账**：总计与平台用量差异大时，用平台数字反推固定开销，不手改单轮数值；只读片段按片段计量，不按整文件计。

## 3. 真实 usage 优先

- 拿得到接口返回的 `usage`（自建客户端直接读 `response.usage`；平台侧逐请求导出）时，按请求贴成 JSONL 用 `--usage` 出表，不再反推底座；拿不到才退回估算口径。
- Trae 里的请求可起 `utils/llm_proxy/llm_proxy.py` 本地代理转发到 DeepSeek，逐请求落 `data/llm_usage.jsonl`（含动作 / 对象，自定义模型把请求地址填代理）。
- **每轮出一次，只记本轮增量**：每轮回复末尾跑 `.venv/bin/python utils/token_cost/token_cost.py --round`，只统计上次出表后新增的请求，不跨轮累计；**统计不单独开轮**，并入本轮最后一条命令（用 `&&` 带出）。上一轮的末次请求会被这一轮自然带上，不必回头重算。
- **固定格式**：脚本倒数第二行是锚点 `- 请求数：X ｜ 起始上下文：X ｜ 结束上下文：X`（起始认本轮首条「提问」，结束认增量末条；提问之前的行只标注「不作锚点」，照常计入成本），数值填进回执的 `- 轮数：X ｜ 请求：X ｜ 上下文：X→X` 行（轮数按批次口径，不带「/ 上限」）；末行是回执里要抄的成本行——`- 成本：输入 X + 输出 Y = 合计 Z`；无新增时输出 `- 成本：未计量（本轮无新增请求，以平台账单为准）`。成本行原样抄，不改写、不换词；明细表可选贴在该行之后。`guard_stop.py` 只认首行「回执：」、轮数行与成本行。

## 4. 工具

- `utils/token_cost/token_cost.py`：按流水 JSON 直接生成上表。每轮用 `--round`（默认读 `data/llm_usage.jsonl`，只出上次出表后新增的请求，游标存 `data/.token_cost_cursor`）；指定区间用 `--usage` 配 `--since <时间>` / `--last <N>`（时间可写 `2026-10-26 20:09:33` 或 `20:09:33`，后者按日志末条日期补全）。
- `utils/deepseek_v4_tokenizer/deepseek_tokenizer.py`：单文件 token 实测。
