## 1. 目标与成功标准

| 项 | 结论 |
|---|---|
| 使用者 | 仅本人，单用户，无注册/权限/多租户 |
| 形态 | 本地 Web 应用 |
| 成功标准 | 连续多天我主动打开它 |
| 首要风险 | 内容不够好 → 我不再打开 |

**反目标（明确不做）**
- 不做通用产品、不做多人使用、不做账号体系
- 不做 AI 自动发现数据源
- **知识聚合**不抓公众号 / 知乎 / 即刻等强反爬平台（铜币拍卖是另一条规则线，见 §14）
- 不做显式点赞反馈
- 不做「AI 直接给调仓指令」这类需要我盲目信任的输出
- 不做插件式数据层抽象
- **知识聚合与铜币拍卖都只接公开接口**，不做浏览器渲染抓取、不做反爬对抗（铜币的那三个小程序网关接口见 §14.3）


## 2. 范围

### 2.1 v1 的两个有逻辑的模块

**模块一：知识聚合**（本节）

`两个入口` 在技术上**不是两套系统**，而是同一套抓取/打分管道 + 两组源配置 + 两个筛选视图。

- **入口 A：Agent 开发**
  - 关注内容：框架与工具动态 / 论文与方法 / 实战案例与踩坑 / 产品与行业动态
- **入口 B：大数据**
  - 关注内容：传统大数据技术栈（Hadoop/Spark/Flink/湖仓/Hive）+ 数据工程与实时计算、数据治理、调度编排

**模块二：铜币拍卖**（独立定义在 §14）

与知识聚合**完全独立**：数据源、抓取管道、数据表、页面无一复用，唯一共享的是同一个服务进程、同一个 SQLite 文件与同一套文档纪律。它由「个人收藏画像 + 麦稀奇站内数据」驱动，不接 RSS。

### 2.2 仅需外壳（无任何业务逻辑）

- 导航栏 + **基金监控** 占位页
- 占位页只显示「未启用」状态，不写任何抓取逻辑（其数据源可达性尚未验证）
- **铜币拍卖**已从占位页升级为正式模块（2026-10-09 决定），见 §14

### 2.3 源策略

- **只接入有 RSS / Atom / 公开接口的源**：技术博客、Newsletter、YouTube/B站频道、掘金类有 RSS 的社区、英文源（HN 等）
- **首批源仅用国内可直连的中文源**：国外源（HN、Google AI Blog、arXiv 等）在本机网络不可达，v1 一律不接（2026-09 实测结论，清单见 plan §15）
- 首批源写死在配置中，跑通后再考虑扩充
- **源给的时间戳也要当数据看，不能盲信**：有的 feed 把本地时间标成 GMT/UTC（InfoQ 中文实测如此，其时间戳整体超前 8 小时），这类源需要在配置里显式声明其时间所在时区，否则日报的显示时间与时效性打分会一起失真（2026-09-23 实测结论，见 plan §12 第 12 条）
- **不接入**公众号、知乎、即刻、小红书
- 每个源记录 `last_ok_at` / `fail_count`；连续失败在界面上标红提示
- **铜币拍卖走公开接口**：麦稀奇的小程序网关免登录、免浏览器（见 §14.3），与本节策略一致

### 2.4 输出形态

- **今日日报**：首页展示当日 5-10 条精选，每条含「打分 + 一句为什么值得看」
- **全量历史**：所有抓到的条目入库，支持按关键词 / 时间 / 入口搜索
- **反馈**：仅隐式记录点击行为（点开了哪条），不做点赞/踩


## 3. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 语言 | Python 3.11+ | |
| 服务 | FastAPI + Uvicorn | 本地起服务，浏览器访问 |
| 存储 | SQLite | 单文件，够用，无需额外运维 |
| 抓取 | httpx + feedparser | 只走 RSS/Atom，不做浏览器渲染 |
| 调度 | APScheduler | 随服务常驻；接受本机休眠漏跑，**不再开机补拉**（2026-10-15，见 §9） |
| 模型 | 国产付费 API（OpenAI 兼容协议） | base_url / api_key / model 全部走配置，可换厂商 |
| 前端 | Jinja2 服务端渲染 + 少量原生 JS | 不引入构建链，降低维护成本 |

## 9. 调度与运行控制

- **不再自动补拉**（2026-10-15 修订）：重启后不抓取、不打分、不采集 —— 服务经常重启，重启一次就烧一遍 token、把各站点打一遍，代价不划算。
- 只保留每天 08:00 的定时执行（具体时间见 §11 待定参数）；**抓取、打分、铜币采集、铜币查价四件事各有独立开关**，关掉后定时任务不再执行它。
- 要立刻跑一次，去「运行控制」页点「立即运行」（手动触发**忽略开关**，后台执行）。
- 调度随服务进程存活；本机休眠/关机期间不执行，接受漏天（不再由启动抓取兜底）。
- **铜币拍卖**：同一服务内、**独立任务**，每天 08:00 与知识日报同批执行（见 §14.8）；其失败不影响知识日报
