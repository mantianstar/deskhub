# deskhub 执行门禁（常驻摘要）

> 本文件只放每轮都要照做的判据；细则、预算、模板统一以 [RULES.md](../../RULES.md) 为准。

## 开工

- 先判类型（判据与模板见 [docs/task-routing.md](../../docs/task-routing.md)）：**Q** 问答（不改仓库，不写卡，≤3 轮）｜**D** 排查（只读，跨 ≥2 文件走 `bug-reproducer`，≤8 轮）｜**S** 小改（写卡，五轮模板，≤10 轮）｜**P** 页面（写卡 + `page-prototyper`，≤12 轮）｜**L** 大任务（写卡 + `planner` 必走，单任务 ≤15 轮）。
- 会改仓库（S / P / L）：第一条回复先出四行「任务卡：」——类型 / 需求原句（不改写）/ 改动链（文件 → 函数或模板 → 测试）/ 读取清单 + 轮数上限，**未出卡不调任何工具**。
- 纯问答、只读分析、代码解释、排查定位（Q / D）：不写任务卡。

## 每轮收口

- 每条回复末尾必须有「回执：」三行（**轮数固定一行** `- 轮数：X / M`、搜索与读取次数含**最多的一项搜索文件 ×N**与**读取累计行数**、**最大单次工具输出 KB**、越界项）+ token 成本清单。轮数行与成本行都只认固定格式：`- 轮数：3 / 10`、`- 成本：输入 X + 输出 Y = 合计 Z`（无新增写 `- 成本：未计量（以平台账单为准）`）；成本行上一行固定 `- 请求数：X ｜ 起始上下文：X ｜ 结束上下文：X`（本轮请求数 / 增量首条与末条已计量请求的输入 token，无请求写 `-`），出数用 `.venv/bin/python utils/token_cost/token_cost.py --round`。缺任一项本轮视为未执行。
- 调用过子代理才追加 `data/conversations/{YYYY-MM-DD}.md`，只记入口与出口。

## 读取与输出

- 先按 [PROJECT_MAP.md](../../PROJECT_MAP.md)「30 秒定位」做精确符号搜索，不靠宽关键词从零探索。**同一文件换到第 3 个关键词前，先跑一次 `^(class|def) ` 拿符号表（类 / 函数名 + 行号），再按行号读**；文件 <120 行直接整段读，不必出符号表。
- `Read` 必须带 `offset` / `limit`，单段 ≤120 行；整份读大文件会被 Hook 直接拒绝——改成分段读，不要原样重试。
- 单轮工具输出 ≤200 行 / 8KB；HTML / XML / 日志 / fixture 只取需要的片段；`pytest -q` 只留末尾汇总。
- **重复即拒，不换写法重试**：`Read` 同区间、`Grep`/`Glob`/`LS` 同 pattern 同范围（含缩到子目录）、`pytest` 同目标（管道 / 重定向 / `-q` 不算新命令）。容忍线是重复率 > 0.8 且新增 < 20 行；口径变了要说明理由。

## 轮次与边界

- 同类动作合并成一次调用（并行读多文件、一次跑完检查）；同一文件同一事实只读 / 验一次；失败两次即停。
- 单任务 ≤15 轮，日常小改 ≤10 轮；第 6 轮仍未跑通即停，列出 2-3 个待定点等确认；超出暂停并说明轮数花在哪。
- 只做被要求的：不改既有文案与测试断言，不做无关重命名 / 重构；「顺手做了」的改动单独列在回复末尾。
