# deskhub 执行门禁（常驻摘要）

> 本文件只放每轮都要照做的判据；细则、预算、模板统一以 [RULES.md](../../RULES.md) 为准。

## 开工

- 会改仓库（代码 / 模板 / CSS / 文档 / 配置）：第一条回复先出三行「任务卡：」——需求原句（不改写）/ 改动链（文件 → 函数或模板 → 测试）/ 读取清单 + 轮数上限，**未出卡不调任何工具**。
- 纯问答、只读分析、代码解释：不写任务卡。

## 每轮收口

- 每条回复末尾必须有「回执：」三行（实际轮数 / 上限、搜索与读取次数、越界项）+ token 成本清单（`.venv/bin/python utils/token_cost/token_cost.py --round`）。缺任一项本轮视为未执行。
- 调用过子代理才追加 `data/conversations/{YYYY-MM-DD}.md`，只记入口与出口。

## 读取与输出

- 先按 [PROJECT_MAP.md](../../PROJECT_MAP.md)「30 秒定位」做精确符号搜索，不靠宽关键词从零探索。
- `Read` 必须带 `offset` / `limit`，单段 ≤120 行；整份读大文件会被 Hook 直接拒绝——改成分段读，不要原样重试。
- 单轮工具输出 ≤200 行 / 8KB；HTML / XML / 日志 / fixture 只取需要的片段；`pytest -q` 只留末尾汇总。

## 轮次与边界

- 同类动作合并成一次调用（并行读多文件、一次跑完检查）；同一文件同一事实只读 / 验一次；失败两次即停。
- 单任务 ≤15 轮，日常小改 ≤10 轮；超出暂停并说明轮数花在哪。
- 只做被要求的：不改既有文案与测试断言，不做无关重命名 / 重构；「顺手做了」的改动单独列在回复末尾。
